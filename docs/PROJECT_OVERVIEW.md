# Project Overview

This document provides a high-level overview of the Drastic Client Portal project structure, focusing on the key files and directories in the root of the repository.

## Core Application Code

*   `src/`: This is the heart of the application, containing all the Next.js pages, components, API logic, library functions, utility code, styles, and type definitions.
*   `public/`: Holds static assets like images, fonts, and favicons that are served directly by the web server.

## Configuration Files

*   `package.json`: Defines project metadata, scripts (for building, running, linting, etc.), and lists dependencies (`dependencies`) and development dependencies (`devDependencies`).
*   `package-lock.json`: Locks the exact versions of installed dependencies, ensuring reproducible builds across different environments. Generated by `npm install`.
*   `next.config.js`: Configures Next.js specific settings, such as build optimizations, environment variable handling, redirects, and more.
*   `tsconfig.json`: Configures the TypeScript compiler (`tsc`) options for the project, including target version, module system, path aliases (`@/*`), and strictness settings.
*   `tailwind.config.js`: Configures Tailwind CSS, defining the theme (colors, spacing, fonts), plugins, and specifying which files Tailwind should scan for utility classes.
*   `postcss.config.js`: Configures PostCSS, a tool for transforming CSS with JavaScript plugins (often used with Tailwind).
*   `.eslintrc.json`: Configures ESLint, the linter used to find and fix problems in JavaScript/TypeScript code and enforce coding style.
*   `.eslintignore`: Specifies files and directories that should be ignored by ESLint (e.g., migration scripts, build outputs).
*   `.gitignore`: Lists files and directories that should be ignored by the Git version control system (e.g., `node_modules`, build outputs, local environment files).
*   `.env.local`: Stores local environment variables for development (e.g., API keys, database URLs). **Should not be committed to Git.**
*   `.env.example`: Provides a template/example of the environment variables required by the project. Safe to commit to Git.
*   `tsconfig.typedoc.json`: An extension of `tsconfig.json` used specifically for generating API documentation with TypeDoc, primarily overriding `"noEmit"` to `false`.

## Documentation & Planning

*   `README.md`: The main entry point for project documentation, typically including setup instructions, project description, and usage guidelines. Resides in the root directory.
*   `docs/`: Central directory for documentation.
    *   `PROJECT_OVERVIEW.md`: This file.
    *   `Overhaul_checklist.md`: The detailed checklist tracking the recent codebase refactoring.
    *   `api/`: Generated TypeDoc API documentation.
    *   `archive/`: Contains archived documentation or analysis files (e.g., `analysis/` directory).
    *   Other specific documentation files (e.g., `RLS_FIX_CHECKLIST.md`, `SECURITY_IMPROVEMENTS.md`).

## Build, Dependencies & Runtime Artifacts

*   `node_modules/`: Directory where all project dependencies (listed in `package.json`) are installed by npm/yarn. Managed via `package-lock.json`. Ignored by Git.
*   `.next/`: Directory generated by Next.js during development and build processes. Contains build outputs, server code, static files, and caches. Ignored by Git.
*   `tsconfig.tsbuildinfo`: File generated by TypeScript to speed up incremental builds. Ignored by Git.

## Version Control

*   `.git/`: Contains all the metadata and history for the Git repository. Managed automatically by Git.

## Service-Specific Directories

*   `supabase/`: Contains configuration and assets related to Supabase, potentially including database migrations (`supabase/migrations/`), local development setup files, or Supabase CLI configurations.
*   `.vercel/`: Likely contains configuration or build outputs related to deployment on the Vercel platform. Ignored by Git.
*   `.specstory/`: Contains files related to the Specstory tool, possibly for visual regression testing or component documentation. Ignored by Git.

## Miscellaneous

*   `next-env.d.ts`: A TypeScript declaration file automatically generated/updated by Next.js to provide type safety for Next.js specific environment variables.
*   `.DS_Store`: A metadata file created by macOS Finder to store folder display options. Should generally be included in `.gitignore`.
